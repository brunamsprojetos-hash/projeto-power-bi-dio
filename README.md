# Projeto Power BI - DIO

Projeto desenvolvido durante o curso de Power BI da DIO.

## Ferramenta utilizada

- Microsoft Power BI Desktop

## Conteúdo

O projeto apresenta dashboards desenvolvidos a partir da base de dados
fornecida durante o curso, explorando indicadores de vendas, lucro,
produtos, países, segmentos e períodos.
